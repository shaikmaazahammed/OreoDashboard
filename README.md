# Oreo Campaign Dashboard 🍪

Interactive Streamlit dashboard for tracking Oreo campaign content and KPIs.

## Features

- Content tracker
- KPI dashboard
- Platform analytics
- Interactive filters
- Charts and visualizations

## Deployment

1. Upload to GitHub
2. Connect repo to Streamlit Cloud
3. Deploy app.py

## Required File

Upload your Excel file here:

data/oreo_content_calendar.xlsx
